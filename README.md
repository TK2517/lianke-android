# 练刻：单人离线健身记录（Android）

这是与宝宝记录软件分离的独立安卓项目。包名为 `com.fitlog.local`，最低 Android 8.0（API 26）。安装包可从本仓库的 v0.2.1 测试版 Release 下载，也可在本机运行 `build.ps1` 生成 `dist/fitlog-debug.apk`。它使用本地调试签名，未发布到应用商店。

功能分类、对初始设想的修正、输入单位和下一步优先级见 [PRODUCT.md](PRODUCT.md)。

## v0.2.1 界面优化

- 首页快捷入口使用一排四个图标与文字组合：记训练、记饮食、记身体、看回顾；采用明亮的浅色卡片。
- 首页沿用宝宝记录软件的日期切换、当天汇总、快速记录和当天记录列表；点记录可进入修改。首页选中过去日期时，快速记录默认使用该日的当前时分。
- 训练项目可搜索内置与历史自定义名称，横向切换最近、常用、本次、身体部位等分类。本次已有的项目再次点选会直接进入“添加一组”，避免无意建出重复项目。
- 新建项目后取消首组输入，会撤销这个空项目；项目与食物选择弹窗会根据结果数量收起多余留白。
- 训练、身体和饮食的时间改为点按选择日期与时分，另有“现在”快捷按钮。新建训练不预设虚构时长，需自行选择开始时间，或点 30/45/60/90 分钟快捷项按实际时长回填；表单显示准备保存的时段与时长。未来时间和结束不晚于开始的训练会被拒绝。

## 已实现

- **训练**：记录开始与结束时间、类型、备注；按项目添加多组次数、重量、时长、距离及 RPE；编辑和删除；最近使用、分类滑动和文字搜索动作。
- **身体**：体重、体脂率、血压、血氧，连同测量时间、设备和备注保存；血压分开保存收缩压和舒张压。
- **饮食**：餐次、时间、文字和照片；从离线食物库中搜索、按分类浏览、收藏、最近使用；按克数计算每餐热量及蛋白质、碳水和脂肪；自建食物和可复用食谱。保存进餐时会保存当时营养数值的快照。
- **回顾**：本周和本月汇总、身体指标趋势及逐日表格；未记录饮食的日子显示“饮食未记”。
- **本地数据**：应用私有 SQLite 和照片目录；没有账号、云同步或 `INTERNET` 权限。设置了关闭系统云备份及设备迁移的规则。通过安卓文件选择器主动导出完整 ZIP 备份（含照片）、恢复备份或导出 CSV。

## 安装和构建

从 Release 下载 `fitlog-debug.apk`，或自行构建后将 `dist/fitlog-debug.apk` 复制到安卓手机并安装。首次安装可能需要允许文件管理器安装应用。安装后先记录一餐或一组训练，确认操作符合你的习惯，再持续使用。

在 Windows PowerShell 中运行 `./build.ps1` 重新构建。需要 JDK、Android SDK Platform 35 和 Build Tools 35.0.0；脚本会在用户目录创建或复用 Android 调试签名密钥。升级安装必须复用同一密钥。若更换电脑而不迁移签名密钥，需要先导出备份、卸载旧版、安装新版、再恢复备份。

## 食物数据和计算边界

随应用提供的 44 种基础食物由 `data/generate_catalog.py` 从 [USDA FoodData Central](https://fdc.nal.usda.gov/download-datasets/) 的 Foundation Foods 2026-04 与 SR Legacy 2018-04 数据生成；每条都保存来源和 FDC ID。生成好的 `app/src/main/assets/foods.tsv` 已入库；大型原始下载档案不入库。若要重建食物目录，先从来源网站下载对应归档文件到 `data/`。中文名称用于界面检索，不能代表任何特定中国品牌或菜馆配方。

营养值按每 100 克数据乘以记录克数计算；食谱按组成食物合计并除以你填写的成品重量。**照片本身不计算营养，未录入的配料、烹调油及饮料不会自动计入。** 自定义食物应优先使用包装营养标签或可信来源。旧版 SR Legacy 数据可能与当前产品不同，包装食品应以实际标签为准。

## 使用边界和数据保护

- 图表只展示记录，不提供血压、血氧或体脂的医学判断；同一设备、相近条件下的长期记录更适合比较。
- 本机存储在卸载应用、清除应用数据或设备损坏后可能丢失。完整 ZIP 备份由你选择保存位置；如果选择云盘作为导出位置，该文件会离开本机。
- 相机入口使用系统相机返回的预览图；从手机文件中选取的图片会压缩后复制到应用私有目录。若需要高分辨率相机直拍，可在后续版本改进。
- 当前食物库以基础食材为主，覆盖不了所有中式菜和品牌食品；需要按实际配方或包装标签新建食物。

## 验证记录

在 Android 15 模拟器中安装并运行过 APK：记录 1 次力量训练与 1 组卧推，记录 150 克米饭得到 195 kcal，添加体重及 120/80 mmHg 血压，查看周报；带照片的完整 ZIP 导出后删除餐食，再从 ZIP 恢复，照片和餐食都恢复；无效备份被拒绝且原餐食保留；CSV 输出检查为 13 列。v0.2.0 还实测了日期与时间选择器、训练时段确认、项目分类、历史自定义项目搜索、本次已有项目直接加组，以及取消首组后不保留新建的空项目。**尚未在真实安卓手机上测试摄像头、不同厂商系统的文件选择器与系统备份行为。**
